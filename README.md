## 这个技能解决什么问题

修正带是典型的 **低价、高频、强季节** 文具品类，绝大多数中小商家会遇到三个死结：

1. **旺季抓不住** —— 修正带 60%+ 销量集中在秋冬学汛期（开学季），错过报名窗口就错过一整年
2. **推广费白烧** —— 客单价 6~10 元，一次点击 0.3 元，出一单毛利才 2 元，**ROI 天生为负**
3. **只会拉流量，不会看结构** —— 不知道浏览量卡在搜索、推荐还是活动，只能盲目加预算

本技能把这些问题拆成可执行的日常动作、量化模型和计算脚本。

## 核心设计理念

### 1️⃣ 先算账，再干活

技能内置**盈亏平衡测算**。修正带的残酷真相：

| 客单价 | 点击价 ¥0.25 | 点击价 ¥0.35 |
|---|---|---|
| ¥5.9 | ROI 0.71 🔴 | ROI 0.51 🔴 |
| ¥9.9 | ROI 1.19 🟡 | ROI 0.85 🟠 |
| ¥15.0 | ROI 1.80 🟢 | ROI 1.29 🟡 |

（毛利率 35%、转化率 3%、退款率 5%、日预算 100 元）

**结论：客单价低于 10 元时，付费投放大概率亏损。**
因此技能给出的核心判断是：

> **付费预算的正确用途是「买权重和坑产」，不是「买流量」。**
> 判定投放是否成功的唯一标准是 **免费流量涨了没有**，而非付费 ROI 本身。
> 想真正盈利，必须把客单价做到 15 元以上（组合装 / 凑单）。

### 2️⃣ 流量缺口量化拆解

把「我要 20000 浏览量」翻译成每个渠道的具体任务：

```
浏览量 = 访客数 × 人均浏览深度
渠道结构：搜索 45% | 推荐 25% | 活动 15% | 付费 15% | 私域 10%
```

`traffic_gap_analysis.py` 输入昨日各渠道数据，输出缺口、优先级和每个渠道该做什么。

### 3️⃣ 踩准全年节点

内置 12 个月的营销日历，标注开学季（2 月 / 9 月）、考试季（6 月 / 12 月）、618 / 双 11 的**提前量**：

| 时间 | 动作 |
|---|---|
| T-60 天 | 备货下单（按淡季 3~5 倍估） |
| T-45 天 | 链接体检（点击率 >6%？转化率 >3%？） |
| T-30 天 | 报名平台专题活动 |
| T-15 天 | 小额开付费测词 |
| T-7 天 | 报名秒杀，确认库存 ≥1000 |
| T+7 天 | 复盘渠道占比与退货率 |

### 4️⃣ 合规优先

技能明确禁止并拒绝协助：**刷单、刷浏览量、虚假交易、好评返现、广告法极限词**。
这些捷径短期有效，代价是限流、罚款、封店 —— 直接毁灭长期流量。

## 快速开始

- Python 3.8+（脚本无第三方依赖）
- 一个支持 Skill 的 AI 助手环境（如 WorkBuddy / Claude Code）

### 安装

```bash

git clone https://github.com/<your-username>/pdd-correction-tape-ops.git \
  ~/.workbuddy/skills/pdd-correction-tape-ops

# 方式二：项目级安装
git clone https://github.com/<your-username>/pdd-correction-tape-ops.git \
  .workbuddy/skills/pdd-correction-tape-ops
```

### 使用测算脚本

**投放盈亏测算**（每次调价前必跑）：

```bash
python scripts/ads_budget_planner.py --price 5.9 --cpc 0.3 --cvr 0.03 --budget 100
```

输出：

```
预计日点击：333 次
预计日订单：10.0 单
预计 ROI：0.59
盈亏平衡点击单价：¥0.059  （当前 ¥0.3，❌ 已超出！）
风险等级：🔴 严重亏损
行动建议：立即停投！先修转化率与客单价，再谈投放
```

**快速对比所有客单价组合**：

```bash
python scripts/ads_budget_planner.py --price 6 --quick
```

**流量缺口拆解**：

```bash
python scripts/traffic_gap_analysis.py \
  --search 2200 --recommend 1100 --activity 300 --paid 600 --private 800 --days 60
```

## 关键运营知识速查

| 项目 | 结论 |
|---|---|
| 全年最大流量窗口 | 8 月中~9 月中（开学季） |
| 第二大窗口 | 2 月底~3 月初（春季学汛期） |
| 小高峰 | 6 月高考中考、12 月底期末会考 |
| 9.9 特卖门槛 | 近 30 天销量 ≥100，评分 ≥4.5 |
| 限时秒杀门槛 | 近 7 天销量 ≥500，库存 ≥1000 |
| 投放铁律 | 只投长尾词，绝不投大词「修正带」 |
| 止损红线 | 烧满 30 元零成交当天关词；7 天 ROI<0.6 且免费流量不涨即全停 |

## 诚实的预期

- 常规月份执行到位：日浏览量 **10000~14000** 属于合格
- **20000+ 最现实的达标窗口是开学季节点**（活动流量可翻 3 倍）
- 淡季（7 月、1 月）目标应主动下调到 8000~10000
- 付费投放不会直接带来盈利（客单低），它的价值是**加速免费流量增长**

> ⚠️ 本技能不承诺任何具体数字目标。任何声称"保证做到 X 万浏览量"的都是骗子。
