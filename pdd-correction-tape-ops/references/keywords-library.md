# 修正带关键词库与标题策略

拼多多搜索流量占成长期店铺流量的 40~50%，是第一杠杆。搜索排名核心指标：**点击率 CTR + 转化率 CVR + 坑产（单链接日销售额）**。

## 核心词根（必埋）

修正带 / 涂改带 / 改正带 / 修正贴 / 涂改液替代

## 长尾词池（按人群与需求分）

**人群词**：修正带学生用、修正带儿童、修正带初中生高中生、办公修正带、考研修正带、公务员考试修正带

**规格词**：修正带3个装、修正带5个装、修正带12个装、修正带大容量、修正带实惠装、修正带批发、修正带迷你、修正带大卷

**属性卖点词**：修正带透明、修正带不易断带、修正带静音、修正带超薄、修正带速干、修正带不留痕、修正带高颜值、修正带可爱卡通、修正带ins风、修正带日系简约、修正带男女通用

**场景/季节词**（节点前埋入）：开学文具修正带、考试专用修正带、考场修正带、开学必备文具、学生开学用品

**价格锚点词**：修正带9.9、修正带便宜、修正带平价、修正带学生平价

## 标题公式（30 字内，权重从左到右递减）

```
[核心词] + [规格词] + [3 个卖点词] + [场景/季节词] + [类目补充]
```

示例：
- 修正带学生用大容量透明不易断可爱卡通涂改带3个装开学文具
- 修正带大容量12个装实惠装静音考试专用涂改带批发办公文具

规则：
1. 一个标题埋 5~8 个词，短词包含长词（「修正带」必在，「3个装」是独立搜索词）。
2. 每周最多改 1~2 个链接标题，每次只替换 2~3 个词——频繁大改会掉搜索权重。
3. 改词前先看后台「搜索词分析」7 天数据：展现高点击低的词换掉，点击高转化低的换匹配人群的词。
4. 违禁词红线：不用「最」「第一」「顶级」「国家级」等极限词。

## 多链接矩阵策略（修正带吃流量的核心打法）

单一链接只能吃一组词。修正带客单低、SKU 天然多规格，用**多链接分别卡位**不同搜索词，叠加起来才能摸到 20000 浏览量：

| 链接定位 | 主吃词 | 价格带 | 备注 |
|---|---|---|---|
| 引流款（单支/2支） | 修正带便宜、平价 | ¥1.9~3.9 | 冲销量权重，可微亏 |
| 主推款（3支/5支装） | 修正带3个装、学生用 | ¥5.9~9.9 | 承接 9.9 特卖，利润主来源 |
| 大包装（12支/批发） | 修正带12个装、批发 | ¥15~25 | 吃班级团购、办公室采购 |
| 高颜值款（卡通/联名/ins风） | 修正带可爱、高颜值、ins风 | ¥4.9~8.9 | 吃推荐流量和女生人群 |
| 场景款（考试/办公） | 考试专用、静音、办公 | ¥6.9~12.9 | 考试季前 2 周重点推 |

矩阵运营规则：
1. 引流款详情页首屏必须导向其他链接（关联销售），把低价流量变成全店浏览量。
2. 新链接冷启动：先靠亲友拼单+老客+9.9 特卖攒 50~100 单基础销量，再谈自然流量。
3. 每条链接都有明确的"主吃词"，改词、出价、主图都围绕它，不要贪多。
