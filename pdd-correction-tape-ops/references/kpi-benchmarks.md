# 数据基准与诊断规则（文具/修正带类目）

晨报诊断的对照基准。数值为行业参考区间，以商家后台「同行对比」实际数据为准，逐月校准。

## 核心指标基准

| 指标 | 及格线 | 良好 | 说明 |
|---|---|---|---|
| 主图点击率 CTR | 4% | >6% | 低于 3% 先换主图，一切优化的前提 |
| 支付转化率 CVR | 2.5% | >4% | 文具类目普遍 2~5%；客单低转化应更高 |
| 人均浏览深度 | 1.5 | >2.0 | 低于 1.3 说明详情页/关联弱 |
| 店铺评分（描述/物流/服务） | ≥4.5 | ≥4.8 | 活动报名硬门槛，掉到 4.5 以下先救评分 |
| DSR 物流 | ≤48h 发货 | 24h 内 | 影响权重与活动资格 |
| 退款率 | <8% | <5% | 修正带质量问题主要是断带、带芯歪 |

## 20000 日浏览量的量化路径（成长期基准）

假设当前日浏览量 5000（访客约 3300，浏览深度 1.5）：

| 渠道 | 当前 | 目标 | 关键动作 |
|---|---|---|---|
| 免费搜索 | 2200 | 8000~10000 | 关键词扩容 + 多链接矩阵 + 坑产冲刺 |
| 推荐流量 | 1100 | 4000~5000 | 内容种草每周 2~3 条 + 高颜值款拉新 |
| 活动流量 | 300 | 3000~4000 | 全活动常驻 + 节点专题（节点期可翻 3 倍） |
| 付费流量 | 600 | 2000~3000 | 小额搜索推广测词，节点加码 |
| 私域/老客 | 800 | 1500~2000 | 包裹卡 + 粉丝群 + 复购提醒 |
| 合计 | ~5000 | 20000+ | 节点期（开学季）最现实的达标窗口 |

时间预期（诚实版）：常规月份做到 10000~14000 属于合格执行；**20000+ 需要踩中开学季/618 这类节点 + 付费加持**，单靠免费流量在淡季（7 月、1 月）极难达标，淡季目标应主动下调到 8000~10000。

## 诊断规则（晨报按此判断）

1. **浏览量跌 >20%**：先查渠道结构——搜索掉查关键词排名/坑产；推荐掉查转化与内容；活动掉查报名状态；全线掉查违规与 DSR。
2. **浏览量涨但转化跌**：流量精度问题——检查付费词是否太泛、活动人群是否错配，宁要 8000 精准访客不要 20000 泛访客。
3. **点击率<3%**：暂停一切加预算动作，先做主图 AB（价格锚点图、场景图、卖点大字图三选一测试）。
4. **坑产连续 3 天下滑**：主推链接排名预警——用限时折扣/满减把日销售额顶回去，搜索权重与坑产强挂钩。
5. **评分掉到 4.6 以下**：全店最高优先级，活动资格和搜索权重同时受罚；排查质量差评源头（断带率、包装）。
6. **单渠道占比 >60%**：结构风险，任何渠道被平台调整都会导致断崖，主动补第二渠道。
